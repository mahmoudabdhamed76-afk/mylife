# My Life — متابعة صحتك اليومية

تطبيق ويب عربي (RTL) لمتابعة **سكر الدم**، **السكر التراكمي HbA1c**، **رحلة الوزن**، **الأكل والسعرات**، **ضغط الدم**، **المياه**، **الرياضة**، و**الأدوية** — كل البيانات محفوظة على جهاز المستخدم، مش على أي سيرفر.

ملف واحد `mylife.html` + سيرفر ثابت بدون أي مكتبة خارجية.

---

## المميزات

| القسم | التفاصيل |
|---|---|
| سكر الدم | قراءات بتوقيتها (صايم / قبل الأكل / بعد الأكل / عشوائي / قبل النوم / أثناء الليل)، شريط تدريج بيوضّح مكان القراءة من النطاق المستهدف، وتنبيه للقراءات الخطرة |
| السكر التراكمي | تسجيل HbA1c + تحويله لمتوسط سكر تقديري، وحساب تراكمي تقديري من القراءات اليومية |
| رحلة الوزن | قياس يومي، نسبة التقدم للهدف، المعدل الأسبوعي بانحدار خطي على ٢١ يوم، التاريخ المتوقع للوصول، سلسلة القياس اليومي، تقويم انتظام ٣٠ يوم، والفرق بين كل يوم واللي قبله |
| الأكل | قاعدة بيانات ~٩٠ أكلة مصرية بالسعرات والكارب + إدخال يدوي، مقسّمة على ٤ وجبات |
| الأدوية | مواعيد الجرعات، تتبع الالتزام اليومي، وإشعارات تذكير من المتصفح |
| التقارير | الوقت في النطاق، المتوسط حسب كل توقيت، رسوم SVG مرسومة بالكود، وتقرير مطبوع جاهز للدكتور |
| المظهر | وضع نهاري / ليلي / تلقائي (يمشي مع إعداد النظام) + حركات انتقال بين القوايم |
| الخصوصية | قفل بكود ٤ أرقام، تصدير/استيراد JSON، وتصدير CSV |
| الألوان | لون مميز لكل قسم (السكر، التراكمي، الوزن، الأكل، المياه، الرياضة، الضغط، الأدوية) بنسختين للنهاري والليلي |
| الحركة | نظام spring كامل: انتقالات بين الشاشات باتجاه الحركة، دخول متتابع للكروت، لمسات دقيقة على كل زر، رسم متحرك للمنحنيات والحلقات، وعدّاد تصاعدي للأرقام — كله على `transform`/`opacity` بس، ومحترم لإعداد «تقليل الحركة» |

## المتطلبات

- Node.js **22 أو أحدث** (بيستخدم ESM و`node:fs/promises` بس — صفر dependencies)

## التشغيل محلياً

```bash
git clone https://github.com/<username>/my-life.git
cd my-life
npm start
# http://localhost:3000
```

للتطوير مع إعادة التشغيل التلقائي:

```bash
npm run dev
```

تقدر كمان تفتح `mylife.html` مباشرة بالدَبل كليك من غير سيرفر — بيشتغل كامل، بس الـ PWA والعمل أوفلاين محتاجين سيرفر.

---

## النشر على Railway

1. ارفع الريبو على GitHub.
2. في Railway: **New Project → Deploy from GitHub repo** واختار الريبو.
3. مش محتاج تظبط أي حاجة — `railway.json` فيه:
   - `startCommand`: `node server.js`
   - `healthcheckPath`: `/healthz`
4. اضغط **Generate Domain** من `Settings → Networking`.

السيرفر بياخد البورت من `process.env.PORT` تلقائياً، فمفيش متغيرات بيئة مطلوبة.

### أو بـ Docker

```bash
docker build -t my-life .
docker run -p 3000:3000 my-life
```

## بنية المشروع

```
mylife.html            التطبيق كامل — HTML + CSS + JS في ملف واحد
server.js              سيرفر ثابت بـ node:http، صفر مكتبات
manifest.webmanifest   إعدادات PWA (تثبيت على الشاشة الرئيسية)
sw.js                  service worker للعمل أوفلاين
icon.svg               أيقونة التطبيق
Dockerfile             نشر بـ Docker
railway.json           إعدادات Railway
```

## التخزين

كل البيانات في `localStorage` تحت المفتاح `mylife.health.v1` — محلي بالكامل، مفيش أي API calls ولا تتبّع. المستخدم بياخد نسخة احتياطية بنفسه من **حسابي → بياناتك**.

> ⚠️ لو كنت مشغّل نسخة قديمة بمفتاح `mizan.health.v1`، صدّر نسخة JSON من القديمة واستوردها في الجديدة.

## تنبيه طبي

التطبيق ده أداة **متابعة شخصية**، وليس تشخيصاً طبياً ولا بديلاً عن استشارة الطبيب. النطاقات المستهدفة الافتراضية عامة ولازم تتظبط مع الطبيب المعالج، والقرارات الخاصة بالعلاج أو الجرعات بترجع للطبيب وحده.
